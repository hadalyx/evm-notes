# evm-notes
Learning notes as I work through Ethereum/EVM internals and  smart contract security. Written primarily for myself —  to think through concepts by writing them out.

These are not tutorials. They're a record of what confused me, 
what I figured out, and what I'm still unsure about. 
Accuracy not guaranteed; corrections welcome via issues.

## Currently learning
- EVM execution model (storage, memory, gas)
- Reentrancy patterns and historical exploits
- Heading toward: Solidity, Foundry, audit practice

## How this is organized
- `notes/` — chronological learning entries
- `topics/` — indexes into related notes (added as themes emerge)
- `resources.md` — sources I found useful
